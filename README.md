# Digital Clock

A lightweight digital clock interface built with HTML and CSS. It displays a centered local-time label and a clock panel with a dark background.

## Run locally

Open `index.html` in any modern web browser.

## Project files

- `index.html` — page structure
- `style.css` — layout and visual styling
- `script.js` — reserved for the clock update logic

## Next step

Add JavaScript in `script.js` to read the current local time and update the `#clock` element every second.
